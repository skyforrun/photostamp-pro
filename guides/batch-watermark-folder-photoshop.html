How to batch watermark a folder of photos in Photoshop

There are four realistic ways to stamp a watermark across a folder in Photoshop, and they differ mainly in how much control you get over the stamp itself. Here is each one, in order of how often it actually works.

Whichever route you pick, stamp into a copy. Actions and scripts that write over the original are how source folders get destroyed.

1. Record an action, then run it through Batch

Open Actions, create a new action, record: place your logo, resize, set opacity, flatten, Save As into a folder. Then File > Automate > Batch, pick the folder, and let it run. The limitation is that the action is fixed — same corner, same size, every image.

2. Image Processor for resize + convert

File > Scripts > Image Processor resizes, converts, and saves in one pass, and its last step can run an action. Useful when your exports vary in size, because you can resize first and stamp after.

3. A droplet on the desktop

File > Automate > Create Droplet turns an action into a standalone app. Drag a folder onto it and it processes. Same fixed-action limit, but handy for repeat clients.

4. A script that asks you for the settings

An ExtendScript panel can prompt for a logo path, a date, an opacity, and a corner, then loop the folder itself. That is the only route where the same tool handles a discreet corner mark today and a tiled diagonal tomorrow without re-recording anything.

Questions

Which is fastest for 500 photos?

A script or a droplet. Both skip the Batch dialog and write straight to an output folder, so you can walk away.

Can Batch read the date from each photo?

Not into a text layer — an action cannot pull per-file EXIF. You need a script for that.

Does the order matter with resizing?

Yes. Stamp after resizing, otherwise the watermark ends up a different relative size on every image.
