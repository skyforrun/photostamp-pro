Add a logo watermark to every photo in a folder

A logo stamp looks trivial until the folder contains a mix of landscape and portrait frames, and every mark comes out a different size. The fix is proportional scaling plus stamping after any crop.

Check one output at 100% zoom before running 500 files. A misplaced mark at thumbnail size looks fine and is obviously wrong full size.

1. Prepare the logo correctly

Export a transparent PNG at roughly 1000px wide. White or black fills are fine; avoid a logo that only reads on one background.

2. Scale by percentage of width, not pixels

A 200px mark is huge on a 1000px preview and invisible on a 6000px master. Set the logo width as a percentage of image width so it reads the same at every resolution.

3. Use a smart object

Place the logo, then convert to smart object. Resizing it later stays non-destructive, and swapping the file updates every instance.

4. Position from the edges

Set margin as a percentage too. A fixed 20px margin disappears on large files and dominates on small ones.

5. Batch it

Run the folder through Batch with a recorded action, a droplet, or a script that takes the logo path as an input. The last option is what lets you reuse the same tool for a different client next week.

Questions

How big should the logo be?

Roughly 15-25% of image width for a corner mark, 8-12% for a tiled pattern.

Should the mark be white or black?

Pick the one that survives your typical background, or use a logo with a subtle stroke so it reads on both.

Can I watermark video stills the same way?

Yes, as long as they are raster files. Batch by frame folder and keep the same percentage rules.
