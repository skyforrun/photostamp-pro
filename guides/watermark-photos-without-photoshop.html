Watermarking photos without Photoshop

If you do not own Photoshop, you can still watermark a folder — but you lose per-image metadata, non-destructive layer work, and control over the exact pixel placement. Here is what the alternatives actually cover.

Privacy is the deciding factor for client work. A local script never uploads a frame; a browser tool necessarily does.

1. Browser batch tools

Upload a folder, set a text or image mark, download a zip. Fast, and fine for a one-off. The costs: upload time, file size limits, and your images sitting on someone else server.

2. Command-line tools

ImageMagick and similar can composite a logo across a folder with one command. Excellent for automation, but you write the geometry yourself and there is no visual preview.

3. Lightroom export presets

If you already edit in Lightroom, the watermarking section in Export handles logo and text marks natively. Limited to a single placement, but no third party involved.

4. When Photoshop still wins

Per-file EXIF dates, tiled patterns that respect non-square crops, smart-object marks, and layered output. If your workflow needs any of those, a script inside Photoshop is the shorter path.

Questions

Is there a free option?

Yes — ImageMagick for scripted use, and the free Lite script on GitHub for Photoshop users.

Do browser tools keep the EXIF?

Most strip it during re-encoding, which also kills your per-photo date.

Can I batch without installing anything?

A browser tool is the only no-install route, at the cost of uploading files.
